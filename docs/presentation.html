Happy Paws — Resumen para presentación

Proyecto: aplicación de gestión para clínica veterinaria — Spring Boot + Thymeleaf

Objetivo

Aplicación CRUD para manejo de clientes, mascotas, citas, productos y ventas, pensada como demo funcional.

Arquitectura

  • Spring Boot (controladores, servicios, repositorios)
  • Thymeleaf para vistas server-side
  • Recursos estáticos: `src/main/resources/static`

Puntos clave

  • Separación por módulos de vistas en `templates/views`
  • Componentes reutilizables en `templates/views/components`
  • Archivos estáticos centralizados en `static/assets`

Recomendaciones de mejora

  • Consolidar partials (header/footer/modals) en `components`.
  • Mover imágenes por módulo: `static/assets/img//`.
  • Eliminar templates duplicadas o vacías y documentar rutas principales.

Cómo ejecutar (rápido)

mvn clean package
./mvnw spring-boot:run
